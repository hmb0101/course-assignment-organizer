# 实验六 近期作业清单助手

个人项目“课程作业要求智能整理系统”的独立命令行实验模块。通义千问根据目标与工具结果提出JSON调用请求，Harness验证、执行并回传结果；不是由程序直接跑完查询与导出的固定流水线。默认样例基准日为2026-10-27，查询区间两端包含。

## 运行

Python 3.10以上，仅标准库，不需要额外安装框架。`sample_assignments.json`为专门编写的5条虚构样例，不是个人真实课程通知；正式数据库和网页不被修改。

将`.env.example`复制为本地`.env`并填写密钥，或者用`--env`指向已有本地配置。密钥不要提交或发到报告中。

```powershell
python agent.py --env .env
python agent.py --env .env --start 2026-10-27 --end 2026-11-03
python -m unittest -v
```

只在运行`agent.py`时请求云端模型；单元测试使用脚本决策替身、本地工具和真实子进程超时，不发出云端请求。云端模型采用`qwen3.8-flash`，temperature=0、max_tokens=700、JSON对象、非流式、关闭思考。认证配置沿用百炼兼容接口，程序不输出认证头。

## 工具与权限

`agent.py`中的`SCHEMAS`是闭合工具白名单，含3个工具：

- `query_assignments(start,end,status)`：固定样例内按日期和状态查询，最长31天；只读。
- `get_assignment_details(ids)`：只读，ID必须来自本次查询结果，不接受重复ID或布尔值。
- `export_summary(ids,filename)`：ID必须已读取详情且覆盖完整目标；文件名不包含路径，只允许指定TXT格式。导出文本由程序依据数据生成，不采纳模型任意写入的内容。

导出前显示文件名、全部文本及影响，必须输入`EXPORT 文件名`才能执行。拒绝、无交互终端或等待超时均不写文件。正式CLI没有自动同意参数；自动化验收使用`ConfirmationGate(simulation=...)`注入同意、拒绝和超时信号，日志明确标记`source=simulation`，不能说成真实用户点击。文件采用独占创建，重复相同内容返回already_exists；不同内容不覆盖。禁止执行Shell、导入模型生成函数、联网抓取或修改作业提交状态。

## Agent与Harness

`Harness.run`发出目标和Schema，接受tool/final两类JSON决策。每个模型响应计1步，默认最多8步；工具名称、参数、权限由`validate_call`检查。模型的原始JSON和对应tool_result按assistant/user角色加入下一轮消息，不只打印结果。模型可调整查询参数或请求读取详情，程序仅规定权限前置和成功标准，不预设每一步模型调用。

限制：模型等待15秒、工具等待3秒、确认等待15秒、总运行60秒、最多2次错误后的修正机会。第3次错误结束；HTTP及网络错误不自动重试。每个模型和工具操作使用工作子进程，超时终止并回收本地子进程；启动回收可能增加少量计时开销。终止本地模型请求不保证服务端停止生成。只读工具异常可回传模型有限修正；写入失败或中止后先核对文件存在与内容，再返回WRITE_REVIEW_REQUIRED，不自动重试。

成功不是模型说“完成”：程序独立核对目标ID、详情是否读取、摘要中的标题和日期、确认后的文件名及导出字节是否与源数据一致。此模块不验证摘要中所有自由文本的语义，仍可能有额外无依据表述，需要人工审阅。

## 状态与记录

每次生成task ID。`artifacts/runs/*.jsonl`逐事件记录北京时间、步数、模型请求、决策、参数摘要、结果、工具耗时、确认和最终状态。完整汇总JSON包含实际上下文、Token用量和停止原因。仅处理虚构样例，并对密钥模式做脱敏。

主要状态：SUCCESS、REJECTED、CONFIRMATION_TIMEOUT、STEP_LIMIT、TIME_LIMIT、CORRECTION_LIMIT、MODEL_TIMEOUT、TOOL_TIMEOUT、WRITE_REVIEW_REQUIRED、CANCELLED。Ctrl+C可终止本地等待；导出途中中断会检查文件，不能直接重试。

## 验收

正常实测目标：整理2026-10-27至2026-11-03的待提交作业，读取要求，确认后导出。预期只有101和102；已交104、区间外103和已逾期105不应混入。固定单元测试覆盖正常、错误参数、工具异常、步数和时间上限，以及确认同意、拒绝、超时；本地脚本决策替身不用于声称真实模型决策。模型正常流程运行证据随课程报告保存，运行产物不提交公开仓库。

后续可替换为个人软件的只读查询适配器。当前不接正式数据库、不自动上传、不实现多Agent或浏览器控制；后续应加强摘要事实校验及更复杂写操作的事务核对。
