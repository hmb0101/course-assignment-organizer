# 实验七 作业通知结构化草稿

这是“课程作业要求智能整理系统”的核心能力原型。将作业通知文字变成可核对的草稿，保留原文并标记待确认字段。不会访问学习通，也不会写入正式数据库。

Python 3.10及以上，仅用标准库。复制本目录的 .env.example 为本地 .env 并配置密钥，或者用 --env 指向已有配置。settings.py 集中管理模型、Prompt、超时和参数。

```powershell
python draft.py --env .env draft --sample N01
python draft.py --env .env draft --file 通知.txt --json
python draft.py --env .env evaluate --output artifacts/v2.jsonl
python -m unittest -v
```

evaluate 使用 cases.json 中12条合成通知，与真实作业日期无关。输出逐条记录，拒绝覆盖已有日志。普通 draft 只展示，不写日志。输入为UTF-8文字，图片、代交、登录和平台抓取不在范围内。模型超时或JSON无效时返回手工录入状态，保留原文。form_seed 可供现有 AssignmentForm 后续预填；用户确认与基础表单校验仍然必要。

v1 是直接调用模型后做字段类型检查的可运行初版，用作固定基线。v2 增加范围预检、逐字证据与本地日期约束。验收依据是实验二 US-01（结构化）、US-02（确认后保存）、US-03（不猜日期）、US-04（故障保留原文）以及多提交物样例。US-02 的正式保存不在原型范围；结果仅可用于后续预填。

## 比较与边界

初版 Commit：`b32043c9be433f943f0207d1c5f84c31bbdc88ff`。在该版本的模块目录以相同命令运行 evaluate，输出到另一个文件。两次使用同一 cases.json、同一模型、温度0、输出上限850 Token、15秒请求等待参数；Prompt和校验规则变化。每次调用记录Token及按公开原价估算的费用，不等于账单。预检返回的越界结果不请求模型。

2026-11-10的两阶段实际运行结果：两版均12/12通过；v2保留42个非空字段的原文证据，实际调用由12次降为10次，Token由3901增至5029。v1、v2全样例耗时中位数分别为1.357秒和2.325秒。记录反映本批样例，不能推断总体准确率或延迟。22项修订版单元测试覆盖超时、坏JSON、冲突日期、越界和证据失配，不发送云端请求。

日期检查优先识别带年份的明确截止日期和明确改期，不能确定时留空。证据出现在原文并不等于语义正确，仍需人工核对否定、引用和冲突。当前不自动换算相对时间，不从图片或网页取内容，不写入正式清单。
