# 课程作业要求智能整理系统

本项目面向需要同时处理多个课程作业通知的大学生。用户粘贴来自学习平台、课程群或教师文档的作业文字后，系统调用通义千问提取课程名称、作业名称、截止时间、提交物、文件命名和任务步骤，由用户确认后保存为结构化任务清单。

## 当前阶段

当前完成个人项目方案、需求说明V1和调研记录，尚未进入功能开发阶段。

## 核心流程

1. 用户粘贴作业要求文字。
2. 系统调用通义千问生成结构化草稿。
3. 用户确认或修改关键信息。
4. 系统保存作业记录并生成任务清单。

## MVP范围

- 文本粘贴和 `.txt`、`.md` 文件导入。
- 作业关键信息智能提取。
- 人工确认、修改和保存。
- 作业列表、详情和完成状态管理。
- API失败时切换到手工录入。

图片OCR、PDF解析、自动抓取学习通、课表同步和系统级通知暂不纳入本学期MVP。

## 技术方案

- Python 3.13
- Django 6
- SQLite
- 阿里云百炼通义千问API

API密钥只通过环境变量或本地 `.env` 文件读取，真实密钥不会提交到仓库。
