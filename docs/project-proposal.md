# 课程作业要求智能整理系统个人项目方案

## 项目背景

大学生经常从学习通通知、课程群消息和教师文档中接收格式不同的作业要求。用户需要手工寻找截止时间、提交物、文件命名和操作步骤，容易遗漏条件或重复查看原通知。

## 目标用户

主要用户为同时修读多门课程、需要独立管理作业进度的大学生。用户能够使用浏览器完成基本操作，但不希望学习复杂的项目管理方法。

## 核心价值

将一段分散、非结构化的课程作业要求转换为经过用户确认的结构化任务清单，减少反复查找和遗漏关键条件的情况。

## 核心用户流程

粘贴作业要求文字 -> 通义千问提取字段 -> 用户确认或修改 -> 保存作业 -> 按清单完成任务。

## MVP功能

- 粘贴文本或导入 `.txt`、`.md`。
- 提取课程、作业名称、截止时间、提交物、命名规则和任务步骤。
- 标记缺失或不确定字段。
- 人工确认后保存。
- 查看、编辑、删除作业并更新完成状态。
- API不可用时使用手工表单。

## 本学期不实现

- 自动登录或抓取学习通内容。
- 图片OCR与复杂PDF版面解析。
- 微信、QQ等平台消息抓取。
- 多人协作、教师端和班级管理。
- 自动替用户提交作业。
- 手机系统级提醒和课表同步。

## 技术方案

采用Django提供页面和业务逻辑，SQLite保存结构化作业记录，阿里云百炼通义千问负责非结构化文本提取。模型输出必须经过字段校验和人工确认后才能写入正式记录。API密钥存放在环境变量或本地 `.env` 文件中。

## 阶段成果

- 需求阶段：项目方案、需求说明V1、用例和验收条件。
- 原型阶段：完成输入、提取、确认、保存的可运行闭环。
- 完善阶段：增加列表管理、异常处理、测试和部署说明。
