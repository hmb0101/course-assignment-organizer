# 实验4迭代记录

## 初版 v0.1.0-initial

- 建立 Django、SQLite 项目骨架和 assignments 业务模块。
- 完成作业列表、新建、详情查看以及任务步骤持久化。
- 提供 `seed_demo` 命令初始化样例数据。
- 首次启动发现 `enumerate` 的生成器参数缺少括号，修正后通过迁移和 `manage.py check`。

## 修订版 v0.2.0-revised

- 增加作业编辑、删除和任务步骤完成状态切换。
- 增加截止时间、重复作业、空步骤和重复步骤校验。
- 所有改变状态的操作限定为 POST，并保留 CSRF 防护。
- 增加空状态、404 错误页面、文件日志、数据清理与恢复命令。
- 建立 9 项自动化测试并全部通过。

## 使用反馈后的界面与需求调整（2026-09-22，未发布）

- 核心“输入要求、人工确认、保存作业”流程不变，智能提取仍留待后续阶段。
- 根据实际作业通常只需提交一份报告的使用场景，取消强制手填步骤和百分比进度，将状态简化为用户手工确认的“待提交／已提交”。对应需求 V1 的 FR-02 中步骤输出和 US-05 步骤勾选，属于小范围需求调整，不是仅更换前端样式。
- 列表显示各状态计数，整行可以打开详情；截止日历支持月份切换、今天定位及日期筛选，不显示右侧步骤预览。
- 详情集中展示截止时间、提交物、提交方式、命名规则、内容要求及原文；内容要求为自由文本，不要求拆分任务。
- 新增字段采用增量迁移，保留旧步骤数据。旧步骤全部完成不代表已提交，现有记录默认仍需用户确认提交状态。
- 验证：34 项 Django 测试通过；浏览器已检查整行跳转、日历与列表筛选、今天定位、月份切换、窄屏日历展开及边界日期；390、768、1024、1200、1440 像素宽度未发现横向溢出。运行的是独立演示数据库，正式数据库未迁移或修改。

## 复现命令

```powershell
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py reset_demo
python manage.py test
python manage.py runserver 127.0.0.1:8000
```
