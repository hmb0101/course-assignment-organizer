# 调研与访谈摘要

## 调研方式

2026年9月8日采用个人使用经历回顾和两次匿名简短访谈。访谈对象均为需要使用学习通和课程群接收作业通知的在校大学生，记录只保留与需求有关的摘要，不保存姓名和账号信息。

## 访谈问题

1. 平时从哪些渠道接收作业要求？
2. 最容易遗漏哪些信息？
3. 目前如何记录截止时间和提交物？
4. 如果系统自动整理，哪些内容必须由本人确认？

## 摘要

- 受访者A：经常在学习通与班级群之间切换，最容易漏看附件要求和文件命名；目前主要依靠备忘录，希望自动整理后仍能查看原文。
- 受访者B：同时处理多门课程时容易混淆截止时间和提交入口；希望系统明确标记不确定信息，不接受AI自行推测日期。
- 个人观察：同一份作业通知常同时包含任务背景、提交物、命名方式和评分要求，手工复制到待办工具时容易只记录标题与截止时间。

## 初步结论

学习平台负责发布内容，通用待办工具负责记录任务，通用大模型能够理解自然语言，但三者都没有直接形成“保留原文、结构化提取、标记不确定项、人工确认后保存”的课程作业闭环。因此本项目把差异集中在确认机制和课程作业专用字段上。
