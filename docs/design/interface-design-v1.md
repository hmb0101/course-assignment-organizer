# 界面与交互设计V1

## 1 页面结构

- 首页与作业列表：显示新建入口、作业摘要、截止时间和完成进度。
- 输入页：提供文本框、`.txt/.md`文件选择、字数提示和智能整理按钮。
- 分析状态页：显示处理中、超时、重试和转手工录入状态。
- 结果确认页：并列显示原文与结构化字段，突出不确定项，保存前必须人工确认。
- 作业详情页：显示提交物、任务步骤和完成状态；V1可与结果确认页复用布局。

## 2 交互约束

- 空文本不能提交；文件类型仅允许 `.txt` 和 `.md`。
- 点击智能整理后禁用重复提交，并显示加载反馈。
- API失败时保留用户输入，提供重试和手工录入两个操作。
- 不确定字段使用“待确认”文字提示，不依赖颜色作为唯一提示。
- 保存前要求用户勾选“已核对原文与整理结果”。
- 删除作业前二次确认；返回上一页时保留尚未保存的输入。
